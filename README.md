# My-Python-Learning-Journey

## 项目简介
这是一个记录我 Python 学习历程的个人仓库。本项目主要用于练习 Python 基础语法、内置模块的使用以及逻辑控制。通过将日常的代码练习整理成 Jupyter Notebook 并上传，旨在构建一个结构化的个人知识库，并为未来回顾复习打下基础。

## 文件说明
当前仓库包含以下两个主要练习文件：
*   **`bmi_calculate.ipynb`**：编写了 BMI（身体质量指数）计算函数，实现了根据身高体重计算 BMI 值，并依据医学标准输出相应的健康状态。
*   **`folder_create.ipynb`**：基于 `os` 模块，利用循环自动批量创建多级嵌套文件夹，常用于深度学习或实验数据的分类存储。

## 代码说明
### 1. BMI 计算器 (`bmi_calculate.ipynb`)
*   **核心功能**：封装了 `fun_bmi(person, height, weight)` 函数。
*   **代码细节**：
    *   使用 `f-string` 语法格式化输出，保留两位小数（`{bmi:.2f}`），使结果展示更美观。
    *   使用 `if-elif-else` 结构处理多重条件判断。

### 2. 批量创建文件夹 (`folder_create.ipynb`)
*   **核心功能**：通过双层 `for` 循环和 `os` 模块，批量生成带编号的主文件夹及子文件夹。
*   **代码细节**：
    *   使用 `f"Sub{i:03d}"` 和 `f"Run{k:02d}"` 进行**字符串补零操作**，确保生成的文件夹按顺序排列（如 `Sub001`, `Sub002`）。
    *   使用 `os.path.join()` 拼接路径，避免跨平台（Windows/Mac）的斜杠问题。
    *   使用 `os.makedirs(..., exist_ok=True)` 代替 `os.mkdir()`，支持创建多级目录，且重复执行不会报错。
